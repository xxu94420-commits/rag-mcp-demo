# AI Agent 概念笔记

## 定义

AI Agent（智能体）是一种以大模型为核心、能够自主完成任务的软件形态。与传统对话系统不同，Agent 不仅能生成文本，还能围绕目标进行规划、调用外部工具、观察执行结果并持续修正。

## 核心模块

1. **任务规划（Planning）**：将复杂目标拆解为可执行的子任务，可借助思维链（CoT）或计划-执行分离的架构。
2. **工具调用（Tool / Function Calling）**：通过结构化接口与外部系统交互，例如查询数据库、调用 API、执行代码。MCP（Model Context Protocol）正在成为工具接入的标准协议。
3. **记忆（Memory）**：包括短期上下文和长期知识库，RAG（检索增强生成）是构建长期记忆的常用手段。
4. **反思（Reflection）**：对执行结果进行自我评估与重试，ReAct 模式将推理与行动交替进行，是经典的反思式循环。

## 典型应用场景

- 研发效能：代码生成、需求评估、测试用例生成、缺陷定位。
- 知识工作：文档问答、报告撰写、数据分析。
- 流程自动化：表单处理、跨系统数据搬运、运维巡检。

## 常见风险

- 幻觉：模型编造不存在的事实，需要用引用溯源和输出校验约束。
- 工具误用：参数错误或权限越界，需要权限控制与人工确认环节。
- 成本失控：长上下文与多轮调用带来高昂 token 开销，需要缓存与裁剪策略。
