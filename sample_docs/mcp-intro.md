# MCP 协议简介

## 是什么

MCP（Model Context Protocol，模型上下文协议）是一个开放协议，旨在让大模型应用以标准化的方式连接外部数据源、工具和工作流。它解决的是"每个 AI 应用都重复造一套插件系统"的问题。

## 架构

MCP 采用客户端-服务器架构：

- **MCP 主机（Host）**：用户直接使用的 AI 应用，如 Claude Desktop、Cursor、IDE 插件。
- **MCP 客户端（Client）**：主机内与服务器保持一对一连接的组件。
- **MCP 服务器（Server）**：暴露能力的进程，向客户端提供三类原语：
  - **Tools（工具）**：可被模型调用的函数，如搜索、查询、计算。
  - **Resources（资源）**：只读数据，如文件内容、数据库记录。
  - **Prompts（提示）**：预设的提示模板。

## 传输方式

- **stdio**：客户端将服务器作为子进程启动，通过标准输入输出通信，适合本地工具。
- **HTTP + SSE**：服务器独立部署，适合远程服务。

## 为什么重要

对开发者而言，MCP 把"给 AI 应用加能力"变成了写一个标准服务器；对企业而言，内部系统只要封装成 MCP 服务器，就能被各种 AI 客户端复用，大幅降低集成成本。
